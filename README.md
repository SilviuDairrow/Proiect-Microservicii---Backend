# Proiect-Microservicii---Backend
În acest proiect am dezvoltat în Python backend-ul unui site tip moodle orientat pe microservicii cu imagini Docker individuale. Am implementat un server gRPC pentru autentificare, restul site-ului fiind dezvoltat pe baza principiilor REST. Pentru stocarea fisierelor am utilizat SeaweedFS și MongoDB pentru stocarea datelor.
